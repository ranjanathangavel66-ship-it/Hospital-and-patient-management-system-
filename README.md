# Hospital Management System

## About the Project

The Hospital Management System is a simple web-based application developed to manage basic hospital and patient information.

## Features

- Patient Registration
- Patient Details Management
- Doctor Information
- Appointment Management
- Patient Search
- Add, Edit, and Delete Patient Records
- Simple and User-Friendly Interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

The main purpose of this project is to make hospital management easier by organizing patient, doctor, and appointment information in one place.

## How to Use

1. Open the Hospital Management System.
2. Enter the required patient details.
3. Add the patient information.
4. View, edit, or delete the records when needed.
5. Use the search option to find patient details.

## Project Type

Web-Based Application

## Conclusion

This project provides a simple and user-friendly way to manage basic hospital information. It helps to reduce manual work and organize patient records efficiently.
